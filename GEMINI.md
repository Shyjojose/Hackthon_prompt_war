# Gemini Project Mandates

This file serves as the foundational mandate for Gemini CLI in this workspace.

## Reference Guidelines
All development must strictly adhere to the standards defined in `PROJECT_GUIDELINES.md`.

## Core Constraints
1. **Size Limit:** Monitor the repository size. Avoid adding large dependencies or assets that would push the repository over the **10MB** limit.
2. **Google Services:** Prioritize the use of Google Cloud/Firebase/Gemini APIs for all smart assistant capabilities.
3. **Architecture:** Use clean, modular architecture that is easy to test and maintain.
4. **Validation:** No code change is complete without passing relevant tests and security checks.
